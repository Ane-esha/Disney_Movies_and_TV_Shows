Disney Movies and TV Shows Analysis

Project Overview

This project analyzes the Disney Movies and TV Shows dataset using Power BI. After cleaning and preprocessing the dataset in Excel, the cleaned data was imported into Power BI for data modeling, analysis, and visualization. An interactive three-page dashboard was created to explore Disney content by title, type, release year, rating, country, and genre, providing insights into the distribution and characteristics of movies and TV shows.

Project Workflow

- Collected the Disney Movies and TV Shows dataset from Kaggle.
- Cleaned and preprocessed the dataset in Excel by handling missing values and correcting data formats.
- Imported the cleaned dataset into Power BI.
- Created additional tables and columns required for analysis.
- Built relationships between tables and performed data modeling.
- Analyzed the distribution of movies and TV shows.
- Explored content by release year, rating, country, and genre.
- Added interactive filters and search options for title, type, year, rating, country, and continent.
- Designed a three-page interactive dashboard to present the findings through visualizations and interactive elements.

Tools and Technologies

- Microsoft Excel 
- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Interactive Visualizations

Key Insights

- Compared the distribution of movies and TV shows available on Disney.
- Explored content trends across different release years.
- Analyzed the distribution of content across different ratings.
- Examined the geographical distribution of Disney content by country and continent.
- Explored the variety of genres available across movies and TV shows.
- Used interactive filters and search options to identify specific titles and analyze content across different categories.

Conclusion

This project provided insights into Disney's content library by analyzing movies and TV shows across multiple dimensions, including release year, rating, country, and genre. The interactive Power BI dashboard makes it easier to explore content distribution and trends, demonstrating practical skills in data cleaning, data modeling, DAX, and dashboard development.
